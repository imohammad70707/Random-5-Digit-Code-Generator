## 🇬🇧 English

### 📌 About

**Random 5-Digit Code Generator** is a simple tool designed to generate random 5-digit numeric codes quickly and easily.

The generated code can be displayed automatically and used in projects that require randomly generated numeric values.

### ✨ Features

* 🔢 Generate random **5-digit codes**
* ⚡ Fast code generation
* 👀 Automatically display the generated code
* 📤 Option to send the generated code
* 🎲 Randomized output
* 🔄 Generate a new code whenever needed

### 📝 Description

This project provides a simple way to generate 5-digit numeric codes.

It can be useful for educational projects, testing, temporary codes, verification-style systems, and other applications that require randomly generated numeric values.

> ⚠️ The generated codes should not be considered cryptographically secure unless a cryptographically secure random number generator is specifically implemented.

### 🛠️ Technology

```text
Language: Python
```

### 🚀 Usage

Run the main Python file:

```bash
python main.py
```

The program will generate and display a random 5-digit code.

### 💡 Possible Improvements

* 🔐 Cryptographically secure code generation
* ⏱️ Code expiration
* 🔄 Automatic regeneration
* 📊 Code generation history
* 🌐 Web-based interface
* 🤖 Integration with bots and other projects
